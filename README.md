# Veil

Hide individual launcher icons (or whole apps) from your app drawer.
Powered by [Shizuku](https://shizuku.rikka.app/).

- Per-icon hiding: disables just one launcher component (`pm disable`), so an
  app with 2-3 drawer icons can keep the ones you want.
- Whole-app hiding: `pm hide` (app vanishes everywhere until restored).
- Everything Veil hides is tracked in the Hidden tab, with one-tap restore.
- Detects when an app re-enables its own icon and offers to re-apply.
